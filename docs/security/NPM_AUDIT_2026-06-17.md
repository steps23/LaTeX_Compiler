# Analisi Vulnerabilità `npm audit` (17/06/2026)

## 1. esbuild

- **Package**: `esbuild`
- **Versione installata**: ^0.25.0 (lockfile risolve tipicamente in 0.25.x).
- **Tipologia dipendenza**: Diretta di sviluppo (`devDependencies` in `package.json`) e potenziale dipendenza transitiva usata dalla toolchain (`vite`).
- **Percorso della dipendenza**: `package.json` -> `esbuild` / `vite` -> `esbuild`.
- **Advisory (GHSA/CVE)**: GHSA-gv7w-rqvm-qjhr
- **Severità**: Alta (2 avvisi correlati riportati da npm).
- **Intervallo Vulnerabile**: < 0.28.1
- **Versione Corretta**: >= 0.28.1
- **`fixAvailable`**: Vite richiederebbe un major upgrade (vite 8.x).
- **Raggiungibilità nel progetto**: L'advisory riguarda il modulo Deno, che manca dei controlli di integrità presenti nel modulo Node. Il progetto corrente utilizza Node.js e Vite, senza fare uso dell'ambiente Deno. Pertanto, la sfruttabilità in questo progetto risulta bassa o non rilevata.
- **Decisione**: Non forzare l'aggiornamento tramite `npm audit fix --force`. L'aggiornamento (compatibilità Vite 8 / esbuild 0.28+) dovrà essere verificato tramite adeguati test in futuro.
- **Fase Prevista**: Stabilizzazione pre-release (Security and testing).

## 2. dompurify

- **Package**: `dompurify`
- **Versione installata**: 3.2.7 (fissata da `monaco-editor`).
- **Tipologia dipendenza**: Dipendenza transitiva di `monaco-editor`.
- **Percorso della dipendenza**: `package.json` -> `monaco-editor` -> `dompurify`.
- **Advisory (GHSA/CVE)**: GHSA-crv5-9vww-q3g8, ecc. (CVE-2026-41238, ecc.).
- **Severità**: Moderata e Bassa.
- **Intervallo Vulnerabile**: < 3.4.0 (in alcune < 3.4.7).
- **Versione Corretta**: 3.4.0+.
- **`fixAvailable`**: Nessun aggiornamento minore diretto, poiché monaco-editor ~0.55.1 dipende strict su dompurify ^3.2.7. Un fix comporterebbe override o upgrade di `monaco-editor`.
- **Raggiungibilità nel progetto**: L'uso combinato di React e le configurazioni standard di monaco-editor non garantisce automaticamente l'inviolabilità; occorre tracciare i code path di interpretazione HTML all'interno del workflow documentale (se esposti, per le tooltip e hover rich text documentali o chat/AI plugins).
- **Decisione**: Monitorare il rilascio di una minor/patch in monaco-editor che aggiorni la dipendenza. Non utilizzare `npm audit fix --force` e non introdurre `overrides` senza una copertura di test stringente.
- **Fase Prevista**: Monitoraggio / Fase di Security Hardening.

## 1. esbuild

### Advisory GHSA-gv7w-rqvm-qjhr

- **Package**: `esbuild`
- **Versione installata**: `0.25.12`
- **Dipendenza**: Diretta di sviluppo (`devDependencies` in `package.json`) e transitiva (tramite `vite@6.4.3`)
- **Percorso della dipendenza**:
  - `latex-compiler` -> `esbuild@0.25.12` (dev)
  - `latex-compiler` -> `vite@6.4.3` -> `esbuild@0.25.12`
- **GHSA**: `GHSA-gv7w-rqvm-qjhr`
- **CVE**: CVE non assegnato / non disponibile nella fonte autorevole corrente
- **Severità**: High
- **Intervallo vulnerabile**: `>=0.17.0 <0.28.1`
- **Versione corretta**: `0.28.1`
- **Valore completo e letterale di `fixAvailable`**:
  ```json
  {
    "name": "esbuild",
    "version": "0.28.1",
    "isSemVerMajor": true
  }
  ```
- **Condizioni tecniche necessarie allo sfruttamento**: Mancanza di verifica dell'integrità del binario nel modulo Deno di esbuild (`lib/deno/mod.ts`), che consente l'esecuzione di codice da remoto via `NPM_CONFIG_REGISTRY` nel caso in cui esbuild venga eseguito in un ambiente runtime Deno.
- **Raggiungibilità nel progetto corrente**: `Non applicabile`
- **Valutazione di Raggiungibilità e Rischio**: Il componente o modulo runtime richiesto non esiste nel progetto. Il workflow e l'esecuzione di TeXForge si basano interamente ed esclusivamente su Node.js e sul bundler Vite, non facendo alcun ricorso all'ambiente runtime Deno.
- **Decisione**: Mantenere la versione corrente di esbuild (`0.25.12`) per la baseline dello sviluppo, poiché l'allineamento a `0.28.1+` richiede l'isSemVerMajor upgrade coordinato con Vite.
- **Fase prevista per la risoluzione**: Security and Testing pre-release.

## 2. dompurify (transitivamente introdotto da monaco-editor)

### Advisory 2.1: GHSA-v2wj-7wpq-c8vv

- **Package**: `dompurify`
- **Versione installata**: `3.2.7`
- **Dipendenza**: Transitiva (tramite `monaco-editor`)
- **Percorso della dipendenza**: `latex-compiler` -> `monaco-editor@0.55.1` -> `dompurify@3.2.7`
- **GHSA**: `GHSA-v2wj-7wpq-c8vv`
- **CVE**: `CVE-2026-0540`
- **Severità**: Moderate
- **Intervallo vulnerabile**: `>=3.1.3 <3.3.2`
- **Versione corretta**: `3.3.2`
- **Valore completo e letterale di `fixAvailable`**:
  ```json
  {
    "name": "monaco-editor",
    "version": "0.53.0",
    "isSemVerMajor": true
  }
  ```
- **Condizioni tecniche necessarie allo sfruttamento**: Bypass XSS dovuto a cinque tag "raw-text elements" mancanti nella regex di validazione interna del parametro `SAFE_FOR_XML`.
- **Raggiungibilità nel progetto corrente**: `Non osservato nel percorso corrente`
- **Valutazione di Raggiungibilità e Rischio**: Non è stata individuata raggiungibilità nel flusso attualmente analizzato; l’assenza di sfruttabilità non è dimostrata e dovrà essere confermata da test di sicurezza dedicati. Sebbene Monaco Editor utilizzi internamente DOMPurify per sanificare hovering e tooltip, l'input LaTeX elaborato non esegue rendering di HTML dinamico o compilazione di template configurati dall'utente.
- **Decisione**: Non applicare automaticamente `npm audit fix --force`. Valutare una nuova release di Monaco oppure un override temporaneo, validato con build, test Monaco e test di sicurezza.
- **Fase prevista per la risoluzione**: Monitoraggio e Hardening.
